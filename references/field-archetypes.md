# 六类领域的替换表

> 这个文件解决一个根本问题：**大部分领域没有 SOTA、没有 benchmark、没有开源代码、没有目标函数。**
> 如果按"算法/深度学习"的模板硬套，会写出空表或编造内容。
>
> 用法：做完第 0 步的类型判定后，来这里查该类领域的六条侦查线、第 4/5 章写法、核验通道、证明标准。

---

## 0. 怎么快速判定类型（三个问题）

问自己：

1. **这个领域的"好"是怎么被量化的？**
   - 在一个公认榜单上比数字 → **A 算法/模型**
   - 用仪器测出来、并与物理极限对账 → **B 系统/器件**
   - 用实验测出来、要别人能重复 → **C 实验科学**
   - 不用数字，用"定理成立/被推翻" → **D 形式科学**
   - 用"达标/合规/成本" → **E 应用/工程**
   - 用"论证是否自洽、史料是否支持" → **F 人文社科**

2. **这个领域最重要的产出物形态是什么？** 代码？样机？数据集？定理？标准？专著？

3. **如果两个人做出相反结论，靠什么裁决？** 复现？测量？证明？史料？监管？——**这就是"证明标准"。**

三个答案基本一致时就定了。不一致时取"裁决方式"那一项，它最能决定报告结构。

---

## A 类 · 算法 / 模型

**特征**：有基准数据集、可复现、在比指标；进步常表现为"某榜单上的数字"。

| 项 | 内容 |
|---|---|
| 六条线 | 综述 / 起源与里程碑 / **方法族与技术路线** / **基准·指标·SOTA** / 近12个月前沿 / 生态（代码、课程、实验室） |
| 第 4 章 | 表：标题 \| 年份 \| 会议 \| 一句话贡献 \| 为什么值得读 \| 代码链接 \| 证据 |
| 第 5 章 | **SOTA 表**：数据集 \| 指标 \| 当前最好 \| 出处 \| 备注（是否同一 split / 同一预处理） |
| 核验 | arXiv / OpenReview / 论文页 / 官方榜单；**特别注意：arXiv 首发年 ≠ 正式发表年** |
| 证明标准 | 在公认基准上超过强基线 + 消融证明每个模块有用 |
| 常见陷阱 | ① 只报一个采样率/一个数据集就宣称全面领先；② 基线没调优（拿通用版当对手）；③ PSNR 涨了但幻觉/感知质量变差 |

---

## B 类 · 系统 / 器件

**特征**：有硬件、有实测、有**物理极限**；核心叙事是"实测 vs 理论极限"。

| 项 | 内容 |
|---|---|
| 六条线 | 综述 / 起源与里程碑 / **系统架构族** / **性能极限与标定方法** / 近12个月前沿 / **器件·实验平台·厂商** |
| 第 4 章 | 表：标题 \| 年份 \| 期刊 \| **系统关键参数** \| 一句话贡献 \| 证据（参数表比结论更重要） |
| 第 5 章 | **物理极限 vs 实测 对账表**：理论极限（含公式与代入值） \| 实测值 \| 超/差多少倍 \| **标定方法** \| 条件（距离/气象/温度） \| 出处 |
| 核验 | 期刊页 + 专利 + 厂商手册 + 标准；**系统参数往往只在正文表格里，摘要不给** |
| 证明标准 | 外场/实测，且**标定方法写清楚**（别人能照着重测） |
| 常见陷阱 | ① "超极限 N 倍"却不给分母（波长/口径是多少？）；② 单次实验当普遍结论；③ 把仿真结论说成实测；④ 不同标定方法的数字横向比较 |

> **这一类最需要的是"分母意识"**：任何"倍数""超越"都必须问清分母是什么、怎么算的。

---

## C 类 · 实验科学（物理/化学/生物/材料/医学基础）

**特征**：有样品/体系、有测量手段、讲可重复性；进步常表现为"新现象/新机制/新手段"。

| 项 | 内容 |
|---|---|
| 六条线 | 综述 / 起源与里程碑 / **体系与样品体系** / **测量手段与指标** / 近12个月前沿（含预印本、会议口头报告） / **仪器·试剂·开放数据库** |
| 第 4 章 | 表：标题 \| 年份 \| 期刊 \| **体系/样品** \| **测量手段** \| 一句话发现 \| 证据 |
| 第 5 章 | **测量手段与指标对比表**：手段 \| 能测什么 \| 分辨率/灵敏度 \| 样品要求 \| 成本 \| 典型误差 \| 出处（**不是排名，是分工**） |
| 核验 | 期刊 + 预印本 + **补充材料**（关键参数常在 SI 里）+ 公开数据库（PDB/GEO/Materials Project 等） |
| 证明标准 | **别人能重复出来**；单一实验室的单次结果不算确立 |
| 常见陷阱 | ① 把"一篇 Nature"当"领域共识"；② 忽略样品/条件差异就对比；③ 混淆"相关"与"因果"；④ 预印本与正式版结论不一致 |

---

## D 类 · 形式科学（数学/理论 CS/逻辑）

**特征**：有定理、证明、反例；**没有数据集，没有 SOTA**；进步表现为"猜想被证明/被推翻/被推广"。

| 项 | 内容 |
|---|---|
| 六条线 | 综述与讲义 / **问题谱系**（问题怎么被提出、变形、推广） / **方法与工具箱**（有哪些证明技术） / **猜想—证明状态** / 近12个月前沿（arXiv +  seminar） / **教材·讲义·知名课程** |
| 第 4 章 | 表：标题 \| 年份 \| 出处 \| **定理陈述（一句话）** \| 用了什么技术 \| 证据 |
| 第 5 章 | **猜想—证明状态表**：猜想 \| 提出者/年份 \| 当前状态（已证/已推翻/部分/开放） \| 关键工作 \| 出处 |
| 核验 | arXiv + 期刊 + 综述讲义 + 会议（STOC/FOCS/ICML theory track 等）；**注意"声称证明"与"被接受"是两件事** |
| 证明标准 | 证明通过同行评审，或反例被验证；**"预印本声称证明"必须标注为未定论** |
| 常见陷阱 | ① 把预印本的"我们证明了"当已确立；② 混淆"数值验证到 N"与"证明"；③ 忽略猜想的原始表述（被后人改写过） |

---

## E 类 · 应用 / 工程（临床医学、制造、土木、农业、能源）

**特征**：有标准、规范、指南、成本；"好"由合规与终点指标定义。

| 项 | 内容 |
|---|---|
| 六条线 | **指南与共识** / 起源与里程碑 / **技术路线与合规要求** / **终点指标·成本·副作用** / 近12个月前沿（含监管动态） / **监管·产业格局·供应链** |
| 第 4 章 | 表：名称 \| 年份 \| 发布机构 \| **适用范围** \| 关键条款/结论 \| 证据（标准与指南本身是"代表成果"） |
| 第 5 章 | **合规与终点指标表**：指标 \| 定义 \| 达标线 \| 当前实践水平 \| 监管要求 \| 出处 |
| 核验 | 标准组织（ISO/IEC/GB/ASTM）、监管机构（NMPA/FDA/EMA）、行业报告、临床注册库 |
| 证明标准 | 达标 / 达到临床终点 / 成本在可接受范围；**多中心、随机对照才算硬证据** |
| 常见陷阱 | ① 拿实验室指标当临床终点；② 忽略地区法规差异（国标 ≠ ISO ≠ FDA）；③ 忽略成本与可及性 |

## F 类 · 人文社科

**特征**：有原始材料、有流派、讲论证；**没有 SOTA，没有"最优"**。

| 项 | 内容 |
|---|---|
| 六条线 | 研究综述/书评 / **思想史与流派形成** / **流派与核心争论** / **史料·案例·原始材料** / 近12个月前沿（新刊、新史料、新译本） / **核心文本·译本·档案馆·数据库** |
| 第 4 章 | 表：作者 \| 年份 \| 出版社/期刊 \| **核心论点** \| 用的材料 \| 学界接受度 \| 证据 |
| 第 5 章 | **流派与争论对照表**：争论的问题 \| 各派立场 \| 各派依据 \| 当前态势 \| 出处（**并列，不裁决**） |
| 核验 | 出版社、期刊、档案馆、数据库；**注意版本与译本差异**（同一文本不同译本结论可能不同） |
| 证明标准 | 论证自洽 + 史料支持 + 同行接受；**不存在"实验复现"** |
| 常见陷阱 | ① 用一个流派的框架去评价另一个流派；② 忽略版本/译本；③ 把"引用次数多"当"结论正确"；④ 替用户裁决学派之争（不该裁决） |

## 混合领域怎么办

真实领域常常跨类。规则：

1. **取"裁决方式"对应的类型为主导**（决定第 5 章怎么写）。
2. 在 `00-定界与计划.md` 里写明：`主导类型 = B；辅以 A（学习型方法的图像质量指标）`。
3. 第 4/5 章按主导类型写，**辅类型的内容作为一个子节或"补充口径"**，不要混在同一张表里。
4. 如果两个类型权重接近（如"医学影像 AI"= A + E），**第 5 章写两张表**，并明确**两套指标不可互相换算**。

## 三种"没有 SOTA"时的第 5 章写法（可直接抄表头）

### 写法一：物理极限对账表（B 类）

```
| 指标 | 理论极限（公式 + 代入值） | 实测值 | 倍数 | 标定方法 | 实验条件 | 出处 |
```
> 关键是**分母必须写出来**。没有分母的"超 N 倍"一律标 `[不可比]`。

### 写法二：测量手段分工表（C 类）

```
| 手段 | 能测什么 | 分辨率/灵敏度 | 样品要求 | 成本 | 典型误差 | 出处 |
```
> 这不是排名，是**分工**。要在表下写出"什么时候该用哪个"。

### 写法三：口径谱系表（任何"指标不可通约"的领域）

```
| 口径 | 指标定义 | 谁在用 | 与其他口径的可换算性 | 陷阱 |
```
> 适用于：多篇论文都报"高精度/低成本/高效率"但定义不同。
> **这张表本身就是重要产出**——它直接支撑 `07-研究机会地图` 里的 `[不可比]` 判断。

### 写法四：猜想-证明状态表（D 类）
### 写法五：合规终点表（E 类）
### 写法六：流派争论对照表（F 类）

后三种的表头见上面对应类型的"第 5 章"行。
