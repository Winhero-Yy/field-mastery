# field-mastery · 领域速通

**一个拒绝编造文献的领域研究技能。**

给它一个领域名，它给你十份可直接使用的文档——其中一份是**研究机会地图**，
告诉你哪些空白是真的、哪些是假的、以及你的第一步该怎么走。

[English](README.md) | 中文

---

## 它解决什么问题

让任何一个足够强的模型"系统研究一下 X 领域"，它都会交给你一份自信、条理清晰的综述。
里面同时也会有：**不存在的论文、指向别处的 DOI、错一个数量级的数字、张冠李戴的作者**。
而这些错误你无法靠读一遍发现——除非逐条核对。

这不是偶发失败，这是**默认失败**，而且**越像样的报告越危险**。

还有两个很少有人提的失败：

- **"尚未解决的问题"清单不是机会。** 它不告诉你这个问题物理上可行吗、有没有人有能力做、
  以及**你手上有什么**可以先做一步。
- **不是每个领域都有 SOTA 表。** 硬给一个没有排行榜的领域套排行榜表，结果只能是空表或编造。

## 四项设计决定

| 设计 | 它挡住了什么 |
|---|---|
| **任何断言都必须带本次会话真实检索到的来源**。拿不到就进"待核实"文件，不进正文 | 编造文献 |
| **核验由另一个从未看过草稿的 agent 做**，告诉它"自己找来源，找不到就说找不到" | 模型给自己判卷 |
| **四态判定**：confirmed / unconfirmed / contradicted / **incomparable** | 把"两篇论文有冲突"和"两篇论文永远不可比"混为一谈——后者更常见，也更致命 |
| **六类领域判定**决定第 4、5 章到底是什么 | 给没有排行榜的领域写 SOTA 表 |
| **独立的机会地图**，固定字段：空白类型、第一步可证伪动作、**实地核实过的**资产 | 把"没人写下来"当成"没人能做" |
| **开检索之前先盘点本地资产** | 漏掉用户自己机器上的未发表初稿/数据集/代码——那往往比网上任何东西都硬 |

## `incomparable` 这一态，一个例子

三篇论文都报"厘米级分辨率"。标定方法不同、目标复杂度不同、气象条件不同。
这**不是冲突**，也**不是互相印证**——而是**看似有共识、实际不可比**。

如果标成 `confirmed`，用户会把"A 比 B 好"写进稿子，然后在审稿意见里被打掉。
本技能为它留了第四态，并强制报告写出"差在哪"。

## 安装

**通过 skills CLI**（适用于 Claude Code、Cursor、Codex、Amp、Cline、DSH 等读取 `SKILL.md` 的 agent）：

```bash
npx skills add https://github.com/<you>/field-mastery --skill field-mastery
```

**手动安装**——把整个文件夹拷到 agent 的全局技能目录：

```bash
git clone https://github.com/<you>/field-mastery.git
cp -r field-mastery ~/.agents/skills/field-mastery
```

常见目录：`~/.agents/skills/`（DSH、Amp、Cline 及通用约定）、`~/.claude/skills/`（Claude Code）。
**文件夹名必须与 `SKILL.md` frontmatter 里的 `name:` 一致。**

**先验证再花钱**：见 [examples/smoke-test.workflow.js](examples/smoke-test.workflow.js)，
一个两路的精简版流程，随便找个窄题目就能确认机制跑得通。

## 用法

直接说清楚领域和你自己的情况：

> 帮我系统研究一下「X」领域。我目前是 Y 方向的研一学生，希望从基础原理开始，
> 全面掌握它的发展历史、关键论文、核心算法、技术路线、前沿趋势，以及目前尚未解决的问题。
> 最后帮我制定学习路线。

报告已经有了之后，追问：

> 根据这个研究报告，X 现在还是空白吗？可能的方向有哪些？

第二种是**追问模式**：它把你问的那个复合词**拆成维度**，逐维判定
（真空白 / 假空白 / 物理不成立 / 检索盲区），**实地核验你手上真有什么**，再更新机会地图。

更多说法见 [examples/prompts.md](examples/prompts.md)。

## 你会得到什么

`<工作区>/领域研究/<slug>/` 下十份文件：

| 文件 | 内容 |
|---|---|
| `README.md` | 一页纸入口：先读哪个、每份干什么 |
| `00-定界与计划.md` | 定界卡、**领域类型**、关键词矩阵（含负关键词）、通道预检、**本地资产** |
| `01-系统报告.md` | 主报告：脉络 → 路线 → 代表成果 → 评价口径 → 前沿 → 未解问题 |
| `02-核心知识-分层讲解.md` | 每个概念五段式：直觉 → 形式化 → 最小例子 → 前置 → 常见误解 |
| `03-知识地图.md` | 无环依赖图 + 三层清单 + 术语中英对照 |
| `04-阅读路线.md` | 按**概念依赖**（不是发表时间）排序的三阶段 + 今天的一个动作 |
| `05-自测题库.md` | 30 题三档，全带答案；C 档题直接来自机会地图 |
| `06-待核实区.md` | 未核实 / 仅书目 / **不可比** / 负面结论 |
| `07-研究机会地图.md` | 空白判定 + 方向卡片 + 可行性排序 |
| `进度.md` | 做到哪了、下一步 |

然后按粒度写入 Mnemon 三层长期记忆：报告 → 项目文档，原子结论 → 记忆空间，一行指针 → 热记忆。

## 它怎么跑

```
Phase 0  定界 + 领域类型 + 本地资产盘点 + 通道预检
   │
Phase 1  六路并行侦查  ──┐  各线按领域类型替换
   │                     │  每条线 ≤8 条，必须带真实 URL
Phase 2  对抗式核验  ────┘  每条派**全新**agent，四态判定
   │                        止损：未核实 >1/3 → 回 Phase 0 重做关键词与通道
Phase 3  写十份产出
   │
Phase 4  落盘长期记忆（三层）
   │
Phase 5  自检，含机械引文 lint
```

## 六类领域

这一步是大多数综述做错的地方。

| 类型 | 第 5 章变成 | 什么算"被证明了" |
|---|---|---|
| **A** 算法/模型 | 排行榜 / SOTA 表 | 基准超过基线 + 消融 |
| **B** 系统/器件 | **物理极限 vs 实测**，且**分母必须写出来** | 外场实测 + 标定方法清楚 |
| **C** 实验科学 | **测量手段分工表** | 别人能重复出来 |
| **D** 形式科学 | **猜想—证明状态表** | 证明或反例 |
| **E** 应用/工程 | **合规与终点指标表** | 达标 / 临床终点 / 成本 |
| **F** 人文社科 | **流派与争论对照表**（并列，不裁决） | 论证 + 史料 |

完整替换表见 [references/field-archetypes.md](references/field-archetypes.md)。

## 测过什么（不是"写完了"，是"测过了"）

- workflow 脚本用 **stub 掉 agent 层**的方式，在 A–F 六类下各真跑了一遍：六条线、label 正确、四键统计正确
- 动态核验上限实测：48 条候选 → 核验 32 条、报告未核验 16 条
- 止损规则实测：未核实 100% 时正确触发
- `scripts/verify_citations.py` 四个回归用例：index-only 豁免、`[不可比]` 接受、两种裸引文正确抓出
- 一次真实领域端到端运行：24/24 confirmed，**0 编造**，并**抓出侦查线里的两处错误**
  （把一项成果的单位归错了，用一手原文纠正）
- 分类器引导（CFG）冒烟测试抓出草稿三处错误：论文年份错（研讨会版早于 arXiv）、
  技术归错了首创者、一条关于"质量—多样性权衡"的断言过强

## 已知局限（直说）

- **中文文献是设计上的盲区**：CNKI、维普、光学期刊站全部拦自动访问。
  技能会明说这一点，并把这件事**派给有校内网的用户**，而不是假装能查。
- **付费墙会赢**：很多断言只能到摘要级。摘要没给的，**一律不填**。
- **C–F 四类已设计但未实地验证**：A、B 两类跑过完整流程，其余四类只过了 stub harness。
- **它慢且贵**：六路并行加对抗核验是**故意的浪费**。浪费本身就是产品。
